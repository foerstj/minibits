# tx-flr

![pic](pic.png)

Terrain texture transition nodes made with consistency.

- Consistent naming scheme starting with (b_)t_aaa01_tx_bbb01-
- No flipped textures - A is A and B is B
- Inner node coords are always the same - center is (0|0|0), and door 1 points in -z direction.

Generic nodes & textures means you can also transition grs01 to grs01.

Done so far:
- Nodes: 04x04 floors b/c/e
- Textures: grs01 / for01 / sn02
