# walk

Take it easy and have a stroll through the beautiful landscapes of Aranna. Nice and slow. Why hurry?

Installation & Compatibility:
- Put the dsres file into the Resources folder of your DS installation
- Made for LoA
- Known conflicting mod: ikkyo_mpsave_beta_6.dsres (thanks for the info, AuraSoul)

Usage:
The mod is applied when a new game is created. This means it will work when you start a new multiplayer session with an existing multiplayer character, but not when you load an existing singleplayer savegame.
